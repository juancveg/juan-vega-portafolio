## Projects Featured

### BuildSafe
Web platform for real-time PPE compliance monitoring on construction sites. Integrates a Python/Flask + YOLOv11 AI service for automatic image-based detection, with a React frontend, Node.js/Express backend, and MySQL database.

### TiendaYa
E-commerce platform built to help small local businesses in Barranquilla go digital. Built with React, Node.js, Express, and MySQL, focused on simplicity and digital inclusion.

### TransporMap
Java application that allows transport operators and users to report road hazards and obstructions in real time using geolocation and an Oracle database.
