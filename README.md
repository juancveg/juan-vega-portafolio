# Juan Vega — Personal Portfolio

Personal portfolio website built to showcase my work, skills, and professional profile as a Systems Engineering student.

**Live site → [juan-vega-portafolio.vercel.app](https://juan-vega-portafolio.vercel.app)**

---

## Built With

| | |
|---|---|
| Framework | Next.js 14 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS |
| Icons | Lucide React · React Icons |
| Deployment | Vercel |

---

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
